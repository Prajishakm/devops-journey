# Useful prompts

## Learning
- "Explain `<command>` like I'm a Linux admin new to DevOps, with 3 examples."
- "Quiz me with 5 questions on <topic>. Don't show answers until I reply."

## Debugging
- "Here is my code and the error. Give me a hint first, not the full fix."

## Review
- "Review this Bash script for bugs and bad practices. Explain why for each."
